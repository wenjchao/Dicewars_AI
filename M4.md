# M4 — Attack Engine Implementation

## Overview
Implement the core attack system with RNG streams, battle resolution, and deterministic action enumeration. This milestone focuses on `AUTO_ALL_BUT_ONE` battle system with proper mask generation and attack validation.

## Goals
- Implement masks and ATTACK validation using `AttackPairs` ordering
- Build RNG streams (`setup`, `turn`, `battle`) with deterministic seeding
- Implement battle resolution with `AUTO_ALL_BUT_ONE` logic
- Ensure `AttackAction.attack_index` consistency with `BattleResult.attack_pair_index`
- Maintain deterministic enumeration order matching `attack_pairs.pairs`

## Architecture

### Core Components
1. **Attack Validation**: Use existing `AttackPairs` from M1 to validate attacks
2. **Battle Resolution**: Implement dice rolling with attacker-first order
3. **RNG Management**: Separate streams for setup, turn progression, and battles
4. **Action Enumeration**: Generate valid attacks in canonical order

   class RNGStream:
       seed: int
       setup_counter: int = 0
       turn_counter: int = 0  
       battle_counter: int = 0
       
       def get_battle_rng(self) -> random.Random:
           """Get RNG instance for battle resolution."""
           # Combine base seed with battle counter for determinism
           battle_seed = (self.seed ^ self.battle_counter) & 0xFFFFFFFF
           self.battle_counter += 1
           return random.Random(battle_seed)

### Phase 3: Battle Resolution
5. **Implement `_resolve_battle()` in `core/engine.py`**:
   ```python
   def _resolve_battle(self, attacker_id: int, defender_id: int, attack_index: int) -> BattleResult:
       attacker_dice = self.state.dice[attacker_id]
       defender_dice = self.state.dice[defender_id]
       
       # Get deterministic RNG for this battle
       battle_rng = self.state.rng_stream.get_battle_rng()
       
       # Roll dice (attacker first for canonical ordering)
       attacker_rolls = [battle_rng.randint(1, 6) for _ in range(attacker_dice)]
       defender_rolls = [battle_rng.randint(1, 6) for _ in range(defender_dice)]
       
       # Apply AUTO_ALL_BUT_ONE rules
       attacker_casualties, defender_casualties = self._calculate_casualties(
           attacker_rolls, defender_rolls, attacker_dice, defender_dice
       )
       
       return BattleResult(
           attacker_rolls=attacker_rolls,
           defender_rolls=defender_rolls, 
           attacker_casualties=attacker_casualties,
           defender_casualties=defender_casualties,
           attack_pair_index=attack_index,  # v5: mirror AttackAction.attack_index
           territory_conquered=(defender_dice - defender_casualties == 0)
       )
   ```

6. **Implement `_calculate_casualties()`**:
   ```python
   def _calculate_casualties(self, attacker_rolls: List[int], defender_rolls: List[int], 
                           attacker_total: int, defender_total: int) -> Tuple[int, int]:
       """Calculate casualties using AUTO_ALL_BUT_ONE rules."""
       # Sort rolls descending for comparison
       att_sorted = sorted(attacker_rolls, reverse=True)
       def_sorted = sorted(defender_rolls, reverse=True)
       
       attacker_losses = 0
       defender_losses = 0
       
       # Compare pairs of highest dice
       for att_die, def_die in zip(att_sorted, def_sorted):
           if att_die > def_die:
               defender_losses += 1
           else:
               attacker_losses += 1
               
       # AUTO_ALL_BUT_ONE: attacker must keep 1 die
       max_attacker_losses = attacker_total - 1
       attacker_losses = min(attacker_losses, max_attacker_losses)
       
       # Defender can lose all dice (conquest)
       defender_losses = min(defender_losses, defender_total)
       
       return attacker_losses, defender_losses
   ```

### Phase 4: Integration & Territory Updates
7. **Update `apply_action()` for attacks**:
   ```python
   def apply_action(self, action) -> ActionResult:
       if isinstance(action, AttackAction):
           # Validate attack
           validation_error = self.validator.validate_attack(action, self.state.active_player_id)
           if validation_error:
               return ActionResult(
                   success=False,
                   error_code=validation_error,
                   # ... unchanged state
               )
           
           # Execute battle
           battle_result = self._resolve_battle(
               action.attacker_territory_id, 
               action.defender_territory_id,
               action.attack_index
           )
           
           # Apply casualties and territory changes
           new_state = self._apply_battle_result(battle_result, action)
           
           return ActionResult(
               success=True,
               new_game_state=new_state.to_public_state(),
               battle_result=battle_result,
               tick_id=str(new_state.tick_id),
               state_hash=new_state.get_state_hash(),
               position_hash=new_state.get_position_hash()
           )
   ```

8. **Implement `_apply_battle_result()`**:
   ```python
   def _apply_battle_result(self, battle_result: BattleResult, action: AttackAction) -> CoreState:
       new_state = copy.deepcopy(self.state)
       
       # Apply casualties
       new_state.dice[action.attacker_territory_id] -= battle_result.attacker_casualties
       new_state.dice[action.defender_territory_id] -= battle_result.defender_casualties
       
       # Handle conquest
       if battle_result.territory_conquered:
           new_state.owners[action.defender_territory_id] = new_state.active_player_id
           # Move 1 die from attacker to conquered territory
           new_state.dice[action.attacker_territory_id] -= 1
           new_state.dice[action.defender_territory_id] = 1
           
       # Advance tick
       new_state.advance_tick()
       
       return new_state
   ```
