# M8 — Observers & UI

## Goals
- Enhance CLI observer with ASCII rendering and snapshot testing
- Create minimal GUI observer using viewmodel transformation
- Implement stable rendering for both CLI and GUI interfaces
- Add map preview functionality
- Ensure observer event ordering correctness

## Overview
M8 focuses on the presentation layer - both command-line and graphical user interfaces. The key architectural principle is separating game logic (already implemented in M0-M7) from presentation logic through a clean viewmodel layer.

---

## Detailed Tasks

### 1. Enhanced CLI Observer & ASCII Renderer

#### 1.1 ASCII Board Renderer
- **File**: `src/dicewars/ui/cli/ascii_renderer.py`
- **Purpose**: Stable ASCII representation of game board
- **Requirements**:
  - Territory-based grid rendering
  - Player color/symbol representation
  - Dice count display per territory
  - Adjacent territory borders
  - Stable output for golden testing

#### 1.2 CLI Observer Enhancement  
- **File**: `src/dicewars/observers/cli.py` (enhance existing)
- **Features**:
  - Board state rendering after each action
  - Battle result visualization
  - Supply phase display
  - Turn notifications
  - Winner announcement
  - Error/penalty notifications

#### 1.3 Map Preview Tool
- **File**: `scripts/preview_map.py`
- **Purpose**: View map layout without running game
- **Features**:
  - Load and validate map JSON
  - Display territory layout
  - Show adjacency connections
  - Territory statistics

### 2. GUI System Foundation

#### 2.1 Viewmodel Transformation Layer
- **File**: `src/dicewars/ui/viewmodel/transform.py`
- **Purpose**: Convert game state to rendering-friendly data structures
- **Functions**:
  - `to_render_state(game_state: GameState) -> RenderState`
  - `to_territory_display(territory_id: int, game_state: GameState) -> TerritoryDisplay`
  - `to_battle_animation(battle_result: BattleResult) -> BattleAnimation`

#### 2.2 Geometry Helper
- **File**: `src/dicewars/ui/viewmodel/geometry.py`  
- **Purpose**: Handle coordinate transformations and layout calculations
- **Functions**:
  - Territory polygon generation
  - Screen coordinate mapping
  - Border line calculations
  - Click-to-territory mapping

#### 2.3 GUI Application Framework
- **File**: `src/dicewars/ui/gui/app.py`
- **Purpose**: Main GUI application window
- **Technology**: tkinter (Python standard library for compatibility)
- **Features**:
  - Game board canvas
  - Control panels (start/stop game)
  - Player information display
  - Action log/history
  - Map selection

#### 2.4 GUI Renderer
- **File**: `src/dicewars/ui/gui/renderer.py`
- **Purpose**: Handle GUI drawing operations
- **Features**:
  - Territory polygon rendering
  - Dice visualization
  - Player color scheme
  - Animation support for battles
  - Interactive territory selection

#### 2.5 GUI Observer
- **File**: `src/dicewars/observers/gui.py`
- **Purpose**: Bridge between game events and GUI updates
- **Functions**:
  - Real-time board updates
  - Battle animations
  - Player turn indicators
  - Game over screen

### 3. GUI Launch Script
- **File**: `scripts/run_gui.py`
- **Purpose**: Launch GUI version of the game
- **Features**:
  - Command-line argument parsing (map file, players)
  - GUI application initialization
  - Game coordinator setup with GUI observer
