# M6 — Penalties & Timeout Windows

## Overview
Implement the penalty system with decision window management, timeout handling, and first-class penalty actions. This milestone focuses on `AUTO_END_TURN` and `SKIP_NEXT_TURN` penalties with proper observer integration.

## Goals  
- Implement decision window start/stop/reset mechanics
- Build `apply_penalty()` producing `PenaltyAction` (no RNG consumption)
- Handle `AUTO_END_TURN` and `SKIP_NEXT_TURN` penalty types
- Ensure v5 first-class penalty actions for observer uniformity
- Handle edge cases: max-turns vs auto-skip precedence, elimination before auto-skip

## Architecture

### Penalty System Design
```python
# Penalty flow:
# 1. Decision window starts before get_action()
# 2. Timeout expires -> apply_penalty() called
# 3. PenaltyAction created (no RNG consumption, tick += 1)
# 4. Observer sees PenaltyAction via on_action_executed()
# 5. Window resets on accept or penalty (not on rejection)
```

### Penalty Types
- **`AUTO_END_TURN`**: Immediately end current player's turn
- **`SKIP_NEXT_TURN`**: Skip the player's next turn opportunity
- **Edge case**: Eliminated players don't get skipped (no `on_turn_start`)

### Window Management  
```python
@dataclass
class DecisionWindow:
    start_time: float
    timeout_ms: int  
    is_active: bool
    pending_skip: Optional[int] = None  # Player ID with pending skip
```

## Deliverables

### 1. Penalty System (`coordinator/penalties.py`)
- **`PenaltyManager`**: Decision window tracking and timeout detection
- **`apply_penalty()`**: Generate penalty actions without RNG consumption
- **Window lifecycle**: Start before `get_action()`, reset on accept/penalty

### 2. Enhanced Engine (`core/engine.py`)  
- **`apply_penalty()`**: Handle penalty action execution

- **`PenaltyAction`**: v5 first-class action with `type: "penalty"`

### 4. Coordinator Integration (`coordinator/loop.py`)
- **Timeout detection**: Monitor decision windows during game loop
- **Penalty application**: Call `apply_penalty()` when timeout expires
- **Turn skipping**: Handle `SKIP_NEXT_TURN` during turn advancement

## Implementation Tasks

### Phase 1: Decision Window Management

1. **Create `coordinator/penalties.py`**:
   ```python
   @dataclass
   class DecisionWindow:
       start_time: float
       timeout_ms: int
       is_active: bool = False
       
   class PenaltyManager:
       def __init__(self, timeout_ms: int):
           self.timeout_ms = timeout_ms
           self.current_window: Optional[DecisionWindow] = None
           self.pending_skip: Optional[int] = None
           
       def start_decision_window(self) -> None:
           """Start decision window before get_action()."""
           self.current_window = DecisionWindow(
               start_time=time.time(),
               timeout_ms=self.timeout_ms,
               is_active=True
           )
           
       def check_timeout(self) -> bool:
           """Check if current window has timed out."""
           if not self.current_window or not self.current_window.is_active:
               return False
               
           elapsed = (time.time() - self.current_window.start_time) * 1000
           return elapsed >= self.current_window.timeout_ms
           
       def reset_window(self) -> None:
           """Reset window on action accept or penalty.""" 
           self.current_window = None
   ```

2. **Update coordinator loop in `coordinator/loop.py`**:
   ```python
   def _get_player_action(self, client: PlayerClient) -> Action:
       """Get action from player with timeout handling."""
       
       # Start decision window
       self.penalty_manager.start_decision_window()
       
       try:
           # Get action from client (this can timeout)
           context = self.engine.get_turn_context()
           action = client.get_action(context)
           
           # Reset window on successful action
           self.penalty_manager.reset_window()
           return action
           
       except TimeoutError:
           # Apply timeout penalty
           penalty_action = self._apply_timeout_penalty()
           self.penalty_manager.reset_window()
           return penalty_action
   ```

### Phase 2: Penalty Action Implementation

3. **Define `PenaltyAction` in `api/types.py`**:
   ```python
   @dataclass
   class PenaltyAction:
       type: str = "penalty"  # v5: first-class action type
       penalty_type: str      # "AUTO_END_TURN" | "SKIP_NEXT_TURN"
       reason: str           # "timeout" | "invalid_action" | "system"
       target_player_id: int # Player receiving penalty
       
       def __post_init__(self):
           if self.type != "penalty":
               raise ValueError("PenaltyAction must have type='penalty'")
   ```

4. **Implement `apply_penalty()` in `core/engine.py`**:
   ```python
   def apply_penalty(self, reason: str, penalty_type: str) -> ActionResult:
       """Apply penalty without RNG consumption."""
       
       penalty_action = PenaltyAction(
           penalty_type=penalty_type,
           reason=reason,
           target_player_id=self.state.active_player_id
       )
       
       new_state = copy.deepcopy(self.state)
       
       if penalty_type == "AUTO_END_TURN":
           # End current player's turn immediately
           new_state = self._handle_auto_end_turn(new_state)
           
       elif penalty_type == "SKIP_NEXT_TURN":
           # Mark player for skip on their next turn
           new_state = self._handle_skip_next_turn(new_state)
           
       # Advance tick (penalties consume 1 tick, no RNG)
       new_state.advance_tick()
       
       return ActionResult(
           success=True,  # Penalties always succeed  
           penalty_action=penalty_action,  # v5: include penalty action
           new_game_state=new_state.to_public_state(),
           tick_id=str(new_state.tick_id),
           state_hash=new_state.get_state_hash(),
           position_hash=new_state.get_position_hash()
       )
   ```

5. **Implement penalty handlers**:
   ```python
   def _handle_auto_end_turn(self, state: CoreState) -> CoreState:
       """Handle AUTO_END_TURN penalty."""
       
       # Transition to SUPPLY if needed, otherwise advance turn
       if state.phase == GamePhase.ATTACK and self._should_enter_supply_phase():
           state.phase = GamePhase.SUPPLY
       else:
           state.advance_turn()
           
       return state
       
   def _handle_skip_next_turn(self, state: CoreState) -> CoreState:
       """Handle SKIP_NEXT_TURN penalty."""
       
       # Store pending skip for target player
       if not hasattr(state, 'pending_skips'):
           state.pending_skips = set()
       state.pending_skips.add(self.state.active_player_id)
       
       # Immediately advance to next player
       state.advance_turn()
       
       return state
   ```

### Phase 3: Turn Skipping Logic

6. **Update turn advancement in `core/state.py`**:
   ```python
   def advance_turn(self) -> None:
       """Advance to next player, handling skip penalties."""
       
       while True:
           # Move to next alive player
           next_player = self._get_next_alive_player()
           
           # Check for pending skip
           if hasattr(self, 'pending_skips') and next_player in self.pending_skips:
               # Skip this player's turn
               self.pending_skips.remove(next_player)
               
               # Edge case: If player was eliminated, don't emit turn_start
               if next_player in self.eliminated_players:
                   continue  # Skip to next player without turn_start
                   
               # Continue to next player (no turn_start for skipped player)
               self.active_player_id = next_player
               continue
               
           # Normal turn start
           self.active_player_id = next_player
           self.phase = GamePhase.ATTACK
           break
   ```

### Phase 4: Max-turns vs Auto-skip Precedence

7. **Implement max-turns precedence**:
   ```python
   def check_max_turns_boundary(self) -> bool:
       """Check max-turns before applying pending auto-skip."""
       
       if self.turn_number >= self.config.max_turns:
           # Max-turns precedence: cancel pending auto-skip
           if hasattr(self, 'pending_skips'):
               self.pending_skips.clear()
               
           self._trigger_game_over("max_turns_reached")
           return True
           
       return False
   ```

8. **Update game over detection**:
   ```python
   def check_game_over(self) -> bool:
       """Check game over conditions with proper precedence."""
       
       # 1. Check max-turns first (v5: precedence over auto-skip)
       if self.check_max_turns_boundary():
           return True
           
       # 2. Check elimination
       if self._check_elimination_victory():
           return True
           
       return False
   ```

### Phase 5: Observer Integration

9. **Update observer events**:
   ```python
   def _notify_penalty_applied(self, penalty_action: PenaltyAction, result: ActionResult):
       """Notify observers of penalty application."""
       
       # v5: Penalties are first-class actions
       for observer in self.observers:
           observer.on_action_executed(penalty_action, result)
   ```

10. **Update coordinator loop for penalty events**:
    ```python
    def _handle_invalid_action(self, action, error_result: ActionResult):
        """Handle invalid action with proper event ordering."""
        
        # 1. Notify invalid action
        for observer in self.observers:
            observer.on_invalid_action(
                action, 
                error_result.error_code, 
                error_result.error_data
            )
        
        # 2. Apply penalty if configured
        if self.config.invalid_action_penalty:
            penalty_result = self.engine.apply_penalty("invalid_action", "AUTO_END_TURN")
            self._notify_penalty_applied(penalty_result.penalty_action, penalty_result)
            
        # 3. Window does NOT reset on invalid action
        # Timeout can still occur
    ```
